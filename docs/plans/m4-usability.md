# M4 사용성 개선 — 입력창·연결 안내·설정 화면

상태: 진행 중(2026-11-01). 요구사항은 [handoff](../handoff.md), 실제 결과는 [상태 기록](../status.md)을 따른다. 사용자 요청에 따라 서명·배포 정책·보안 심사 같은 보안 정책 항목은 이 범위에 넣지 않는다. 페어링 등 기존 보호는 바꾸지 않는다.

## 배경 — 2026-11-01 리뷰 실측

Linux Chromium headless와 합성 OpenCode fixture에서 측정했다. 추론 옵션(variant)이 있는 모델을 쓰면 메시지 영역이 다음처럼 줄어든다.

| 패널 크기 | 메시지 영역 |
| --- | --- |
| 400×900 | 221px |
| 400×760 | 81px |
| 400×700 | 21px |
| 400×640 | 12px(보내기 행이 화면 밖) |
| 320×700 | 29px |

입력창이 423px이고 그중 모델 선택 블록이 239px이다. 메시지 영역 위의 머리글·환경 요약·실행 설정·제목 행이 256px이다. 입력창 선택 UI는 2026-10-27 합의안(삭제된 `browser-controls-expansion.md` §3, 커밋 `94d2aa1`)의 `[현재 모델 ▾] [추론 옵션 ▾] [현재 에이전트 ▾]` 한 줄 배치를 따른다. 현재 구현은 라벨 행·검색·능력 설명이 세로로 쌓여 이 배치보다 크다.

## 과제

- [ ] **P1 입력창 압축과 상단 행 통합**
  - 모델·추론 옵션·에이전트를 라벨 행 없이 한 줄의 기본 `select`로 둔다. 접근 이름 `모델`, `모델 variant·추론 옵션`, `에이전트`는 유지한다.
  - 이미지·시각 조작 능력 표시는 지우지 않고 한 줄로 줄인다. 모델 검색·즐겨찾기는 접힌 상태로 둔다.
  - 입력란은 2줄에서 시작해 내용에 따라 늘어난다. 단축키 안내는 placeholder로 옮기고 첨부 버튼과 보내기를 한 행에 둔다.
  - 환경 요약과 실행 설정 행을 한 행으로 합친다. 머리글의 브라우저 작업 중단 버튼은 작업이 있을 때만 보인다.
  - 완료 기준: 400×640/700/760과 320×700에서 메시지 영역 200px 이상, 보내기 버튼이 화면 안에 있다.
- [ ] **P2 상태별 시작 화면과 한국어 오류**
  - Bridge 페어링 필요·연결 끊김·실행 환경 없음·준비 중·준비 실패·대화 없음마다 다음 행동 버튼을 보여 준다. 버튼은 설정에서 페어링, 다시 연결, 실행 환경 추가, 다시 시도다.
  - Bridge·실행 환경의 영문 오류는 한국어 설명과 다음 행동으로 보여 준다. 원문은 접힌 상세에 남긴다.
- [ ] **P3 작은 개선**
  - 복사하면 완료 표시를 보여 준다. 되돌리기 확인은 창 대신 메시지 안에서 묻는다.
  - @현재탭이 잘렸으면 그 사실을 표시한다. 초안 텍스트는 `chrome.storage.session`에 보존한다(첨부 제외).
  - 띄어쓰기가 빠진 안내 문구 4개를 고친다. 최소 글자 크기는 11px로 한다.
  - 도구 카드 본문은 펼쳤을 때만 그린다. 도구 이름과 작업 기록 결과는 한국어로 표시한다.
- [ ] **P4 설정 화면**
  - Bridge에 연결되면 페어링 입력을 접는다. 프로필 ID는 기존 검증 규칙을 지켜 자동으로 만든다.
  - 연결 진단은 ✓/!/✗ 목록으로 보여 주고 원본 JSON은 접어 둔다.
- [ ] **P5 문서**: 사용 설명서, 설치 안내, UI 설계 기록을 새 화면에 맞춘다.
- [ ] 과제마다 실패 테스트를 먼저 쓴다. 직접 영향받는 테스트를 실행하고, 마지막에 전체 Linux 회귀를 돌려 status에 기록한다.
