# Windows 설치 마법사와 경로 오류 개선

사용자 보고: 사내 PC에서 `D:\Multimedia\AgentBrowser`를 선택하고 Bridge 시작을 누르면 소유자 오류가 발생한다. 후속 요구는 일반적인 Windows 설치 마법사 형식이다. 사내 PC에는 접근할 수 없으므로 실제 소유자 원인은 미확정이다.

- [x] 설치 전 시작·페어링 노출, 폴더 변경 시 상태 잔류, 완료 후 연결 안내와 권한 오류를 실패 테스트로 재현.
- [x] 시작 → 위치 → 준비 → 진행 → Chrome 확장 추가 → 페어링 → OpenCode 설정 → 완료. 각 화면은 한 작업만 제공하며 고급 설정은 별도 창으로 분리. 뒤로·다음·설치·마침 및 설치 후 자동 시작.
- [x] 권한 오류의 실제 경로·복구 안내 추가. 개인 PC의 로컬 D 드라이브 오탐 수정, 소유자·하위 삭제·교체 방어 유지.
- [x] 실제 Windows 마법사와 기존 설치·업데이트·제거 회귀 검증.
- [x] 로컬 검토용 패키지 및 문서·상태 기록.

기존 운영 설치·전역 OpenCode 설정은 변경하지 않는다. 로컬 완료 후 사용자가 버전 증가와 배포를 명시적으로 요청했다. 후속 배포는 [v0.1.7 릴리스 계획](./2026-10-13-release-0.1.7.md)을 따른다.

실제 결과: Windows 설치 엔진 64/64, 마법사·경로 7/7 및 최종 ZIP의 네이티브 컨트롤 GUI 흐름 통과. 사내 경로·물리 마우스·실제 Chrome 페어링은 미검증으로 상태 기록에 구분했다.
