# 최종 검토·문서 보강·v0.1.9

요청 범위는 설치·런타임·진단·업데이트의 상세 검토, 필요한 수정, 문서의 민감한 환경 정보 일반화와 새 버전 배포다. 기존 동작·검증 기록은 사실대로 유지하되 실제 조직의 경로·계정·정책·구성 비율을 사례로 싣지 않는다. 공개된 태그·자산이나 Git 이력을 몰래 교체하지 않는다.

- [x] WSL 사전 검사와 실제 Windows 실행의 차이를 회귀로 확인하고 수정한다.
- [x] 새 탭·이동·requestId 보고를 우선 재현하고, 수십 개의 구체적인 성공·오류·중단 시나리오를 실제 Windows Chrome에서 실행한다. 패널→실제 OpenCode→MCP 통합과 합성 API/모델 검사를 구분한다.
- [x] GUI·스크립트의 설치 경로 신뢰 검사, 진단 보고서, 업데이트 처리 경계를 검토하고 확인된 문제를 수정한다.
- [x] 설치·첫 연결·업데이트·복구·제거·보고서 공유 문서를 구현에 맞춰 보강한다.
- [x] 현재 문서 및 새 배포물에서 실제 환경 식별 정보와 정책 우회로 오해할 안내를 제거한다.
- [x] 영향받는 테스트와 실제 Windows 설치·업데이트·WSL MCP를 실행하고 한계를 기록한다.
- [ ] PR·최종 CI, 게시할 ZIP 검증, v0.1.9 게시와 다운로드본 재검증을 완료한다.

전체 보안 감사를 완료했다거나 접근하지 않은 환경의 장애를 해결했다고 주장하지 않는다. 실제 업무 페이지는 사용하지 않으며, 모델 시험은 허용된 Zen 무료 모델만 시도하고 성공·차단을 구분한다. 기존 운영 설치와 전역 OpenCode 설정은 보존한다.
